# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in EM4me, please report
it privately through GitHub:

1. Open the [Security advisories](https://github.com/Stumm-Consulting-GmbH/em4me/security/advisories)
   page of this repository.
2. Click **Report a vulnerability** and describe what you found.

Please do not open a public issue for a security vulnerability. Issues are
visible to everyone, and a vulnerability should be fixed before it becomes
public.

A useful report contains the EM4me version, the steps to reproduce the
problem, what you expected to happen, and what happened instead.

## What happens with a report

Reports are read by the maintainer and handled confidentially until a fix is
released. You will be credited in the release notes if you wish; just say so in
your report.

## Supported versions

Security fixes are released as a new version of EM4me. Only the latest released
version receives fixes; earlier versions are not patched. If you are running an
older version, please update to the latest release from
[em4me.ch](https://em4me.ch).
