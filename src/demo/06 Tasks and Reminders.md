# Tasks and reminders

Checkbox lines become interactive tasks. Click a box in Reading or Live view to toggle it. Back to [[00 Welcome]].

## States

Beyond open and done there are extended states, each with its own glyph and colour:

```markdown
- [ ] open
- [x] done
- [/] in progress
- [>] delegated
```

- [ ] Skim the whole demo area
- [x] Open this file
- [/] Try editing a task line
- [>] Show the app to a colleague

## Dates and priority

Markers at the end of the line add a due date (📅), a scheduled date (⏳) and a priority (🔺 highest, 🔼 medium, 🔽 low):

```markdown
- [ ] Submit report 📅 2099-03-31 🔺
```

- [ ] Plan the week ⏳ 2099-01-06 🔼
- [ ] Submit report 📅 2099-03-31 🔺
- [ ] Tidy the backlog 🔽

## Reminders

A separate marker, ⏰, fires a notification at a chosen time — distinct from the deadline. Reminders run only while the app is open; a catch-up dialog gathers any missed ones at the next start.

```markdown
- [ ] Call the supplier back ⏰ 2099-04-14 09:30
```

- [ ] Call the supplier back ⏰ 2099-04-14 09:30

Set one with **Set reminder** (default `Ctrl+Alt+R`) on a task line, or use the full **Edit task…** dialog for every marker at once.
