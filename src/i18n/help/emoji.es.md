# Emoji

Los códigos emoji como `:smile:` se renderizan como emoji Unicode: :smile:. La aplicación admite el conjunto completo de GitHub (unos 1900 códigos, incluidos alias como `:+1:`).

## Funcionamiento y límites

- Solo se convierten códigos `:code:` reales; los códigos desconocidos quedan como texto.
- Los patrones con dos puntos en el texto están protegidos: horas como 12:30, URL y construcciones similares siguen siendo texto.
- Las formas de emoticono como `:)` u `8-)` deliberadamente **no** se convierten (evita falsos aciertos).
