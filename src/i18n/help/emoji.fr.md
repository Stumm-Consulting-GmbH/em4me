# Emoji

Les shortcodes emoji comme `:smile:` se rendent en emoji Unicode : :smile:. L'application prend en charge le jeu GitHub complet (environ 1 900 codes, alias comme `:+1:` inclus).

## Fonctionnement et limites

- Seuls les vrais shortcodes `:code:` sont convertis ; les codes inconnus restent du texte.
- Les motifs à deux-points dans le texte courant sont protégés : les heures comme 12:30, les URL et constructions similaires restent du texte.
- Les formes émoticônes comme `:)` ou `8-)` ne sont volontairement **pas** converties (évite les faux positifs).
