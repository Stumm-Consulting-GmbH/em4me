# Emoji

Emoji shortcodes such as `:smile:` render as Unicode emoji: :smile:. The app supports the complete GitHub set (around 1,900 codes including aliases such as `:+1:`).

## How it works, and limits

- Only real `:code:` shortcodes are converted; unknown codes stay plain text.
- Colon patterns in running text are protected: times such as 12:30, URLs and similar constructs remain text.
- Emoticon short forms such as `:)` or `8-)` are deliberately **not** converted (avoids false hits in running text).
