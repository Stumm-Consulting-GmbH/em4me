# Emoji

Gli shortcode emoji come `:smile:` si renderizzano come emoji Unicode: :smile:. L'app supporta il set GitHub completo (circa 1900 codici, inclusi alias come `:+1:`).

## Funzionamento e limiti

- Solo i veri shortcode `:code:` vengono convertiti; i codici sconosciuti restano testo.
- I pattern con due punti nel testo sono protetti: orari come 12:30, URL e costrutti simili restano testo.
- Le forme emoticon come `:)` o `8-)` deliberatamente **non** vengono convertite (evita falsi riscontri).

## Riferimento completo

L'elenco completo degli shortcode è mantenuto dal [cheat sheet emoji di ikatyang](https://github.com/ikatyang/emoji-cheat-sheet), generato automaticamente dall'API emoji di GitHub — copre esattamente il set usato dall'app. Il collegamento si apre nel browser predefinito.
